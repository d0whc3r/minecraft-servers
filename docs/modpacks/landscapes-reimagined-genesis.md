# Landscapes Reimagined Genesis Server

**Modrinth**: https://modrinth.com/modpack/landscapes-reimagined-genesis  
**Type**: Create and exploration modpack (Fabric)  
**Tags**: create, tech, exploration, building  
**Minecraft Version**: 1.20.1  
**Modpack Version**: 3.2 Finale  
**Memory**: 8GB initial allocation

## Overview

Landscapes Reimagined Genesis combines Create, large-scale terrain generation,
structures, quests, and performance mods. Version 3.2 is the final planned
release unless the authors publish a critical fix.

## Quick Start

```bash
./scripts/validate-config.sh landscapes-reimagined-genesis
./scripts/start-server.sh landscapes-reimagined-genesis
docker logs -f mc-landscapes-reimagined-genesis
# Wait for: "Done! For help, type 'help'"
```

## Connection

- **Address**: `landscapes-reimagined-genesis.<MC_ROUTER_DOMAIN>` through mc-router
- **Version**: Minecraft 1.20.1 with Genesis 3.2 Finale
- **Client**: Install the same 3.2 release from Modrinth

The `.mrpack` declares 267 files for both sides and 32 client-only files. The
Modrinth installer filters client-only content from the dedicated server.

## Configuration

Configuration file: `config/modpacks/landscapes-reimagined-genesis.env`

```bash
TYPE=MODRINTH
MODRINTH_MODPACK=landscapes-reimagined-genesis
MODRINTH_VERSION=pBrfi38A
MODRINTH_LOADER=fabric
VERSION=1.20.1
JAVA_VERSION=java17
MEMORY=8G
LEVEL_TYPE=minecraft:default
RCON_PORT=26595
```

The profile uses the official `.mrpack` directly. The commercial server pack
advertised by the authors is not required for this installation method because
the Modrinth manifest declares dedicated-server support and pins the loader.

## World Generation

Terralith, Regions Unexplored, the structure mods, and bundled data packs modify
the normal world type. Keep `LEVEL_TYPE=minecraft:default`; no separate preset
is required. World-generation changes apply to newly generated chunks.

## Voice Chat

Simple Voice Chat is included, but this repository does not publish UDP port 24454. Normal gameplay works without it. Enabling voice chat requires an
explicit Compose networking change.

## Performance Tips

- Treat 8GB as a starting allocation and monitor actual memory use.
- Keep the configured 10-chunk view and 8-chunk simulation distances initially.
- Generating new terrain is more expensive than revisiting existing chunks.
- Back up the world before changing the pinned release or world-generation mods.

## Troubleshooting

### Client reports a mod mismatch

Confirm that every client uses Genesis 3.2 Finale. The server is pinned to
immutable Modrinth version ID `pBrfi38A`.

### Expected terrain or structures are missing

Verify that the world was generated by this release and inspect newly generated
chunks. Changing world-generation mods does not rebuild existing chunks.

### Voice chat does not connect

This is expected with the default repository networking because UDP 24454 is not
published. The Minecraft game connection still uses mc-router normally.
